# Security policy

Please do not disclose vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available. If it is unavailable, contact the repository maintainers through the private contact options provided by the `rockstar-bio` GitHub organization.

Include a clear description, affected files or routes, reproduction steps, impact assessment, and any suggested mitigation. Do not include credentials, personal data, or live download URLs that should remain private.

The maintainers will acknowledge reports when possible, investigate responsibly, and coordinate disclosure after a fix or mitigation is available. This project does not promise a particular response time.
