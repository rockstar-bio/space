# Roadmap

## Phase 1 — Open-source preparation and sponsorship application

Remove provider-specific runtime code, establish contribution and content policies, document the architecture, and apply for infrastructure sponsorship.

## Phase 2 — Cloudflare sponsorship decision and R2 infrastructure planning

Confirm the sponsorship decision, capacity, credits, security boundaries, delivery model, and operational ownership before provisioning production infrastructure.

## Phase 3 — Cloudflare R2 storage implementation

Implement the storage provider behind the existing TypeScript interface, including metadata, listing, search, temporary URLs, thumbnails, and large-file delivery.

## Phase 4 — Verified, resumable migration from OneDrive

Design and approve a migration that preserves source data, supports resume, verifies checksums and metadata, and records failures for review.

## Phase 5 — Public file browser, search, thumbnails, and downloads

Release the public browsing experience after content review, storage validation, and safe download delivery are complete.

## Phase 6 — Performance, security, reliability, monitoring, and community contributions

Improve observability, abuse resistance, accessibility, performance, incident response, documentation, and contributor workflows.
